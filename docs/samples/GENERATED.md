# Cheerful Labrador puppy

`cheerful-puppy.png` was generated for this project with the built-in image-generation tool at the owner's request. It is an AI-generated sample, not a photograph of a real dog. README screenshots show the actual editor processing this sample.

## Generation prompt

Use case: photorealistic-natural. Asset type: sample photo for a tasteful photo-editing app and its interactive website. Primary request: a very cute, cheerful chocolate-brown Labrador puppy. One young puppy with soft velvety cocoa fur, big soulful amber-brown eyes, oversized floppy ears, round paws, a happy relaxed open mouth and a tiny pink tongue, a slight inquisitive head tilt. Sitting on a sunny lawn with small white daisies, looking toward the camera. Warm gentle morning light, joyful spring mood. Realistic editorial pet photography, natural anatomy and detailed fur, softly blurred pale sage-green garden background. Landscape 3:2 composition, entire puppy including paws and ears comfortably inside the frame, centered with generous clear background around its silhouette so this photo works for foreground segmentation. Puppy occupies about 60% of frame height. Beautiful restrained colors, warm chocolate contrasting with fresh green; no oversaturation. No collar, props, accessories, text, logos or watermark. Generate a brand new image, not an edit of the earlier dog photo.
